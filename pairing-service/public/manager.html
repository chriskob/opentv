Recording to Synology NAS (SMB Guide)

Configure OpenTV to write live TV recordings directly to a shared folder on your Synology NAS:

  • Create a shared folder in DSM Control Panel (e.g. /recordings).
  • Ensure DSM File Services → SMB is enabled.
  • In OpenTV Settings → Recording → Storage Target: Select Network Drive (NAS / SMB).
  • Enter your Synology NAS IP and SMB credentials.
